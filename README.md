# Portfólio — João Ribeiro

> Portfólio pessoal com as minhas informações, competências e experiência profissional — site estático feito em HTML, CSS e JavaScript.

![Preview](assets/images/hero.png)

## Descrição

Este é o meu repositório do portfólio pessoal. O site apresenta uma página única (single-page) com seções de apresentação, sobre, competências, formação e experiência.


## Tecnologias

- HTML5
- CSS3 (styles personalizados)
- JavaScript
- Bibliotecas usadas: `particles.js`, `typed.js`, `vanilla-tilt` e `font-awesome` para ícones

## Estrutura principal

- `index.html` — página principal
- `assets/css/style.css` — estilos principais
- `assets/js/` — scripts (partículas, efeitos, comportamento)
- `assets/images/` — imagens usadas no site

## Preview

Abra `index.html` no seu browser ou use um servidor local para testar. 

Use a extensão Live Server do VS Code e clique em "Go Live".
